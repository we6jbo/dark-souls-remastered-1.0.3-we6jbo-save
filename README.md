# Dark Souls Remastered v1.0.3 — we6jbo Character Archive

This repository is a structured archival record of **we6jbo**, a Dark Souls
Remastered character originally played on **Nintendo Switch**. It is intended
for game-preservation research, personal save reconstruction, compatibility
testing, character-build documentation, and offline recreation on PC.

## Important scope

`we6jbo-character.json` and `9259757.txt` describe the recorded character.
This project does **not** contain the Dark Souls Remastered game, FromSoftware
code, Nintendo firmware, or a tool for bypassing online anti-cheat systems.

The recorded values were transcribed from a player's own character. Some
displayed attack and defense values are snapshots derived by the game and are
kept as observations rather than treated as intrinsic editable item statistics.

## Character

- Name: **we6jbo**
- Level: **259**
- Covenant: **Chaos Servant +2**
- Source platform: **Nintendo Switch**
- Recorded target game version: **Dark Souls Remastered 1.0.3**
- Recreation goal: a close offline PC mirror of the recorded character

## Reconstruction target

The intended PC reconstruction starts at the **beginning of NG+**. Starting
class and starting gift are intentionally recorded as unknown because they are
not required to reproduce the present SL259 build. Appearance, sex/body type,
human/hollow state, attuned spell arrangement, quick-item slots, and weapon
slot arrangement are treated as configurable presentation/loadout choices rather
than blockers. The historical Switch inventory is preserved verbatim in the
archive, while the GUI separately identifies story keys/progression items that
should reset for a clean NG+ beginning.

## Data quality

This archive preserves the player's transcription while correcting obvious
spelling of game terms. Where a transcription is uncertain, the structured data
should be treated as a record to verify against the Nintendo Switch character
rather than as an authoritative game database.
