## Current technical findings

- Lordvessel warping is modeled after defeating Ornstein and Smough, reaching
  Gwynevere, and receiving the Lordvessel.
- Warp targets are restricted and must also have been rested at.
- Kiln of the First Flame has published map references. The simulator uses an
  original local schematic rather than redistributing third-party map art.
- Semantic Scholar works without authentication for many endpoints; an API key
  is optional for many uses and can be requested.
- Anthropic API access is a separate Console/billing path. Academic degrees do
  not automatically create a free Anthropic API entitlement.
- Local Ollama remains the preferred no-cloud path when practical.
- v84 treats research publication as deterministic local packaging. A KOSMOS
  provider failure or missing Anthropic key cannot block writing the sanitized
  research package.
- External-AI communication is free-first. Semantic Scholar can support
  unauthenticated literature research but is not an LLM. A configured Gemini
  Free Tier project may receive the public-safe teaching bundle. Paid external
  AI remains disabled by default.
- The external-AI total-spend ceiling is **$34.00**. The simulator uses a local
  kill switch and never auto-enables a paid provider.

### Communicating findings back

Search engines generally cannot autonomously write back to a GitHub project.
AI agents or human researchers can propose a GitHub issue/PR, propose entries
for `docs/research-ai-responses.json`, or give the project owner structured
feedback for import through the Credentials tab. The simulator validates
imported findings locally.

## Completion policy

Tasks at 100% in `progress.json` are skipped by active research unless the user
deliberately resets them. A bounded verification task may remain below 100% while
being temporarily skipped by the scheduler until a targeted new source becomes
available; this prevents repeated generic searches from monopolizing the research loop.
