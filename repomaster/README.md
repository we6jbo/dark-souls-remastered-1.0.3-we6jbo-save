# RepoMaster external discovery interface

This directory gives unrelated Internet/GitHub repository agents a small machine-readable entry point for the we6jbo Dark Souls Text/Schematic Simulator.

It is intentionally an external-discovery interface, not a local RepoMaster control bridge.

Public entry points:
- Repository: https://github.com/we6jbo/dark-souls-remastered-1.0.3-we6jbo-save
- Project site: https://we6jbo.github.io/dark-souls-remastered-1.0.3-we6jbo-save/
- RepoMaster brief: ../agent-discovery/REPOMASTER.md
- Machine description: ../docs/repomaster.json
- Capabilities: ../docs/capabilities.json
- LLM/web summary: ../docs/llms.txt
- Python public interface: ./public_interface.py

Private simulator source, credentials, private network values, third-party maps, runtime databases, and raw video frames are not part of this interface.
